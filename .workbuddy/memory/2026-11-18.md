## Intel Mac 出包启动器支持（分支 mac/intel-packaging-launcher，7 个提交，未推远端）

- 目标：让当前 x86_64 / macOS 26.7.3 / Xcode 26.5 机器构建可运行的 S2Arm.app，驱动 iPhone IPA + 资源包出包；**不**在 Intel Mac 跑 Switch 游戏（宿主必须 arm64 原生执行，无 DBT 后端）。
- 改动：x86 Python/轮子钉版与 RID、runtime 版本记录覆盖所有钉版依赖、preflight 接受 x86 出包、Intel 壳跳过本机不可用的 ShellUI、iOS 27 API 按 `__IPHONE_27_0` 双重门控、声明最低系统从包内 Mach-O minos 实读、末步重命名对代理双执行幂等。
- 构建命令（本机复现必须带这些环境变量，否则沙箱/工具选择会失败）：
  `CODEBUDDY_SAFE_DELETE_ENABLED=0 S2A_RUN_ROOT=<repo>/build/macos/runroot S2A_SHELL_CACHE=.../runroot/s2arm/cache/shell PATH="/usr/bin:/bin:/usr/sbin:/sbin:~/.dotnet:<cmake bin>:<meson bin>:~/.local/bin" S2A_PY=<repo>/build/venv/bin/python3 S2A_GMAKE=<repo>/build/macos/gmake/bin/make <venv python> launchers/macos/build_app.py`
- 结果：`build/macos/S2Arm.app` 构建成功（BUILD_APP_RC=0），x86_64 可执行、codesign 严格校验通过、声明最低 macOS 26.0、iOS/tvOS 预编壳齐备；`open` 启动成功，内置 s2armctl CLI 可用，applenv 从 App 内置运行环境检查除 Apple ID（安装阶段才需要）全绿。
- 测试：launcher 配置单测 12/12、macOS 兼容 2/2、文档一致性 24/24 通过。`test_s2armctl.ControlStuckTests` 3 项失败是本机既有问题（本次改动前同一批就已失败，与 x86 改动无关）。
- 文档：坑记录已追加两条（旧 SDK 编译门控 / minos 声明），README 已更新 Intel 支持说明。

## 打开 App 报「内置引擎产物缺失」修复（提交 e23bbca56）

- 根因：`pack/jobs/core.py` 的 `Context.env()` 无条件取 `S2ArmGame.app` 宿主；Intel 出包 App 按设计没有这个 AArch64 宿主，`embedded.artifact()` 把「清单无此项」当包坏，导致 preflight / import 在环境准备阶段就抛错（日志全绿但作业失败）。
- 修复：`artifact(..., optional=True)` 只在 x86_64 且清单确实无宿主项时返回 None；列了但文件缺失、以及 Apple Silicon 行为完全不变（负对照验证仍抛「重新安装」）。
- 验证：4 项 bundled-host 测试通过；engine-heal / IPA-packaged / macOS-compat / docs 一致性回归通过；干净重建 App `BUILD_APP_RC=0`，codesign 严格校验通过；启动 App 后真实 `preflight` 作业 `succeeded`，无新引擎缺失错误。

## iPad 通用 IPA 缺游戏库修复（提交 9322764d1 / 178349689 / 5cd870cde）

- 现象：Intel 出包正常，但装到 iPad 打开提示 `This version is missing the game library`。
- 根因：之前为绕开 xcodebuild 报 iOS 运行时不可用，把 Intel iPhone 壳的 ShellUI 整段跳过；通用容器必带库界面。后来 iOS 平台组件已装，但 xcodebuild 经 SwiftPM 在临时出壳镜像里调 sandbox-exec 被本机拦（`sandbox_apply: Operation not permitted`）。
- 修复：Intel 的 iPhone 壳不再跳过 ShellUI；xcodebuild 路径保留给 arm64/tvOS，Intel 改用 `swift build --disable-sandbox --triple arm64-apple-ios18.0 --sdk <iPhoneOS.sdk>` 出 `libS2ArmShellHost.a` + 资源包，链接用 `-force_load` 保证弱引用入口进壳。
- 验证：重建 App `BUILD_APP_RC=0`；新壳 ID `4859388ae1d9690f`，壳二进制含 `_s2a_shell_library_vc` / `_s2a_shell_set_play_handler`，资源包在 `Shell/root/S2ArmShellUI_ShellUI.bundle`；用 App 现场 `assemble_shell` 出的 `S2Arm.ipa` 解包含库符号与资源包；13 项配置测试、24 项文档一致性、4 项 bundled-host 测试通过。
- 注意：用户此前用旧 App 出的 IPA 需要重新出包并重装到 iPad；App 已重新打开。
