# 2026-11-19

## 小内存 iPad 起局 Break 排查与动态窗口修复（7f917b3ac）

- iPad mini 6 连点两次同款游戏都是 `nninitStartup` 里 `SetHeapSize(3234 MiB)` 越出 3072 MB 窗口，Break `0x1003 OutOfMemory`；不是游戏文件缺失、不是崩溃。
- 根因：Switch SDK 按应用池（3285 MiB）申请堆，与游戏大小无关；`vawin.c` 在 6 GB 空洞上固定留 3 GiB 给宿主，窗口只剩 3 GiB。
- 修复：`s2a_window_host_below_for_pool(fit, learned, pool)` 按 NPDM 应用池给窗口、宿主下限 2 GiB；单款从 NPDM 读池，多款容器取最大；越窗时记录 `heap_need` 并走 heap_learned 提示页。
- 验证：新壳号 93f5f8fc6da983bc，IPA 壳含新符号；`t_vawin_learned` 0 处不符、负对照 3 处红；Launcher 配置 13/13、文档一致性 24/24；真机运行未验，需用户用新包重测。
