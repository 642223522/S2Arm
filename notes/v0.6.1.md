# S2Arm v0.6.1

这是 0.6.0 的修复版，修的是从 0.5 升上来以后「更新旧版安装的游戏」推不上去的问题（#1756）。从 0.5 升到 0.6.0 后，电脑上「更新」跑完游戏旁边还是「更新」、手机上提示要导入 .s2arm 的玩家，升到 0.6.1 后再点一次「更新所选」即可。
*A fix release for 0.6.0. It fixes Update installed games not reaching the phone after upgrading from 0.5 (#1756). If, after moving from 0.5 to 0.6.0, the computer still showed Update when it finished and the phone asked you to import an .s2arm, update to 0.6.1 and run Update selected once more.*

## 修复
- **Windows：「更新这 N 款 / 更新所选」不再一款都推不上去**：从 0.5 升上来的 Windows 玩家点更新，每款约 1.5 秒就失败，报「应用自带的预编壳缺失」。现在启动器给每一项操作都带上随包的预编壳和资源，更新能正常推到手机。
  *Windows: Update N games / Update selected works again. Players who came from 0.5 saw every game fail after about 1.5 seconds with "the app's bundled prebuilt shell is missing". The launcher now passes its bundled shell and resources to every operation, so updates reach the phone.*
- **Mac：「更新所选」里有一款没推成，会照实报失败并可重试**：原先某一款推送失败会被吞掉，整单照样显示完成，按钮却还是「更新」。现在 Mac 上会整页写出因为什么没推成，点「重试」从没推成的那款接着推。Windows 上没推成时，顶栏「游戏库」会亮橙色提醒；写出原因、失败页和「重试」，Windows 下一版补上。
  *Mac: Update selected now reports a game that did not make it and lets you retry. A failed push used to be swallowed and the whole job still said done while the button kept saying Update. On Mac a full page now says why it did not go through, and Retry continues from that game. On Windows the Library tab in the top bar turns orange when a push fails; the reason, failure page and Retry come to Windows in the next release.*
- **Windows：从 0.5 升级后第一次打开启动器，不再提示「游戏库没建好」**：升级后首次打开时几项后台操作同时排队用游戏库，其中一项会撞上 Windows 的「文件正在使用」而报错。现在不会了。
  *Windows: the first launch after upgrading from 0.5 no longer says the game library is not set up. Several background tasks queue for the library on that first launch, and one of them could hit Windows' "file in use" error. That no longer happens.*
- **Mac：推送时偶尔「找不到设备」会自己换一条路推**：推游戏程序包时，如果推送工具一时找不到连着的 iPhone，现在改用系统自带的设备通道接着推，不再直接失败。
  *Mac: an occasional "device not found" during a push now falls back to another route. If the push tool briefly cannot find the connected iPhone while sending a game's program, it continues through the system's own device channel instead of failing.*

## 系统要求
- 与 0.6.0 相同：Mac 需要 Apple 芯片、macOS 15 或更新；Windows 需要 64 位 Windows 10 或 11；iPhone / iPad 需要 iOS / iPadOS 18 或更新。
  *Same as 0.6.0: Mac with Apple silicon on macOS 15 or later; 64-bit Windows 10 or 11; iPhone / iPad on iOS / iPadOS 18 or later.*
