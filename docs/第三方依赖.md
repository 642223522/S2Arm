# 第三方依赖与来源

完整清单（组件、版本、许可、来源、进不进 .app / IPA / APK）只维护一份，在仓库根目录 [THIRD_PARTY_LICENSES.md](../THIRD_PARTY_LICENSES.md)。S2Arm 本身以 Apache License 2.0 授权，见根目录 [LICENSE](../LICENSE) 与 [NOTICE](../NOTICE)。

加或升级第三方组件时，直接改根目录那份清单，按其中「维护」一节写全版本、来源、许可文件位置和进包情况。


### Linux Vulkan 测试容器

`tests/vulkan/Dockerfile` 使用微软官方 .NET SDK 10.0.403 noble 多架构镜像（固定 manifest-list SHA-256），Ubuntu 固定快照提供 Mesa lavapipe、Khronos validation、shaderc/glslc、SPIRV-Tools、Vulkan loader/headers 与编译工具。来源、精确摘要、显式准备和许可边界见 [共享 Vulkan 环境](../tests/vulkan/README.md)。组件及其许可证保留在镜像/发行版包内，不复制第三方源码到仓库，不随门禁隐式下载。
