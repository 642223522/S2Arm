# ARM64 循环只读定位器（R6）

```sh
python3 tools/arm64_loops.py <合法自有NSO> > <本地报告.json>
bash tests/arm64_loops_test.sh
```

沿用 `tools/rewriter-requirements.txt` 的 Capstone 5.0.7 / LZ4 4.4.5，不联网安装。
工具复用 `arm64_aspect_locator.py` 的 NSO 段校验、固定依赖和异常屏障；不调用
改写器、不执行输入、不写 NSO、不输出补丁或运行时配置。报告含地址及反汇编，
只在本地分析；不要把游戏输入、解包产物或完整报告上传到仓库。

## 输出与边界

- `cyclic_regions`：解码后的**直接、过程内 CFG** 的全部有环强连通分量，
  含节点、内部边、外部入口及访存。单节点自边也算。它覆盖多入口不可约环和
  无已知入口的孤立环，不指数枚举每一条简单环。
- `loops`：上述区域中能用支配关系证明的自然循环；`header` 是入口，
  `back_edges` 是“目标支配来源”的回边。相同入口的多个回边合并；内外层
  自然循环分别列出。不能证明唯一入口的区域仍保留在 `cyclic_regions`，
  不任取最小地址当入口。
- 入口证据仅来自 text 起始地址、已解码直接调用目标、区域外部的已知直边。
  不猜函数边界；没有可见来边的函数循环可能只有区域记录、没有自然循环记录。
- `memory` 含 Capstone 内存操作数和 ARM64 literal 访存（包括预取），列出
  基址、索引、位移、写回；literal 地址不当作基址寄存器。不是实际访存轨迹。
- `base_strides` 单位是字节/从 header 到任一回边的一轮。只有所有此类路径
  都得到相同仿射增量，才给数值；0 表示基址不变。支持同一 64 位寄存器的
  ADD/SUB 立即数和无别名的立即数 pre/post-index 写回。增量按 A64 64 位
  模运算理解，不证明指针合法、没有溢出或有效访问范围。
- 路径增量不同、未知写入、W 寄存器零扩展、调用、嵌套循环的重复次数等
  无法证明时，值为 `null` 并附原因。嵌套循环自己的步长仍可单独证明。
  索引寄存器变化不等于基址变化，不能据此推出有效地址步长。
- 调用只保留可能返回的 fallthrough，不把被调用函数内联；步长遇调用
  一律未知（不假定 ABI 保存）。RET 终止；间接跳转、异常/调试转移、非法字
  不猜后继，并列入 `unresolved`。因此**不是包含未知间接边的完整运行时 CFG**。
- 按 4 字节解码整个 text，可能把内嵌数据当合法指令；不证明可达、会执行、
  循环会终止或发生多少次。`execution_proven=false` 永远保留。静态候选不能
  替代真实游戏/真机证据，也不意味着允许自动改写这些循环。

## 有界失败与验证

默认输入及总解压上限 64 MiB、指令槽 200000、单有环区域 2048 节点；可通过
`--max-bytes`、`--max-instructions`（最多 2000000）、`--max-region`（最多 4096）
显式配置。复杂/大 NSO 可能超限；此时退出 2，**stdout 不输出残缺 JSON**，
不能把失败解读成零循环。仅接受普通文件，拒绝 FIFO/设备；段重叠、截断、
对齐、声明尺寸、压缩和存在的段哈希校验沿用已登记 NSO 校验器。

测试只使用原创合成 NSO 与固定机器码，期望地址/增量独立写定；覆盖自环、
嵌套、多回边、多入口、孤立环、间接边、异常屏障、调用、条件增量、别名、
写回、字面池、压缩、预算及 CLI 输入不变。Linux 主机测试不等于 ARM64 执行、
Mac/Metal、安装、设备、游戏或性能验证。工具未接入出包或运行时，苹果产物
路径没有改动。
