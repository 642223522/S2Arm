## 现在能领的任务

### A. 设备普查（不写代码，最需要人）
拿自己的设备、自己的游戏，用新层起一局，把结果贴成 Issue（模板「安卓 / 鸿蒙新图形层 · 设备普查」）。骁龙 8 Elite 以外的任何芯片都是新读数：Mali、其它 Adreno、Xclipse、PowerVR、麒麟 / 鸿蒙设备。

步骤：按下面「怎么编出新层的包」装包 → 在应用里导入游戏 → 设备接电脑 → 跑：

```bash
bash android/tools/nvk_survey.sh <程序号> 60
```

脚本直连起一局、等 60 秒，在输出目录里写 `report.md`、`logcat.txt`、`crash.txt`、`screen.png`。它只读数，不改设备上的游戏和存档。

回报什么（`report.md` 里都有，整段贴进 Issue）：
1. 机型、芯片、系统版本、刷新率；
2. 程序号（不写游戏名）；
3. **未接清单**：新层遇到没接的命令不会停，按「类别 名字」记一笔、每种只打一行，一局列全——这张清单就是这台设备、这款游戏还缺什么；
4. 其它带【红】的日志行，去重计数；
5. 最后一行呈现读数（已呈现多少帧、丢多少帧、累计绘制多少笔、跳过多少笔）；
6. 画面情况：看本地的 `screen.png`，在 Issue 里用文字选（正确 / 全黑 / 缺东西 / 花屏 / 没出画面）。**截图不上传**；
7. 进程是否还在；崩了把 `crash.txt` 一起打包上传。

## 规矩

- **契约头一次一人改**：`graphics/nvn/gfx/nvn/nvn_backend.h`（现在 v4）和两个平台接口头的改动统一经维护方。要加入口先开 Issue 说要什么、为什么，不要直接在 PR 里改头。
- **不按厂商分支**：后端只按能力查询的结果走，不读厂商号和设备号。
- **没接的不许静默**：核心里没接的命令、后端做不了的事，一律走 `nvn_unimpl(类别, 名字, 位置)` 记账，不空实现、不写假结果。
- 仓库里的文字（代码注释、文档、提交说明、Issue）用程序号，不写游戏名；不上传游戏文件、密钥、存档、游戏截图。
- 一个任务一个 PR；测试的期望值要能不跑被测实现就算出来。

## 怎么编出新层的包

工具与一次性准备同 [android/README.md](../android/README.md)「Which build path to use」：macOS（Apple 芯片）走宿主构建，Linux 走 docker。下面是 macOS 的命令。

要装的：Android SDK（platform 36、build-tools 36.0.0、NDK 29.0.14206865、CMake 3.31.6）、JDK 17、python3、git。.NET 由准备脚本自己引导一份固定版本，不用另装。

```bash
# 一次性（要联网）：下固定版本的 .NET、NuGet / Gradle 依赖与编解码库源码
bash android/host/prepare.sh

# 编新层的调试包：比缺省构建多三个环境变量和一个 Gradle 属性
S2ARM_ANDROID_CS_SERVICES=static S2ARM_ANDROID_VK_ENGINE=1 S2ARM_ANDROID_VK_BACKEND=nvk \
  bash android/host/build.sh -Ps2arm.nativeMode=game :app:assembleDebug

# 产物
ls android/app/build/outputs/apk/debug/app-debug.apk
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

| 变量 | 作用 |
|---|---|
| `S2ARM_ANDROID_VK_BACKEND=nvk` | 选新图形层；不设就是旧层 `nvn_vk` |
| `S2ARM_ANDROID_VK_ENGINE=1` | 把共用的图形前端编进包 |
| `S2ARM_ANDROID_CS_SERVICES=static` + `-Ps2arm.nativeMode=game` | 能起游戏的构建（服务层静态链进单库）；不带是只有外壳的诊断包 |

装好后怎么确认跑的是新层：起一局后日志（`adb logcat -s S2Arm`）里有一行 `nvk session: backend open on <显卡名>`。没有这一行就是包没带 `nvk` 编。

导入游戏：在应用里用自己的游戏文件和密钥导入（同现有安卓流程）；游戏文件和密钥不进仓库、不进 Issue。
