# 游戏缺陷修补表

`<main 构建号前 16 位>.tsv`：游戏自己代码里的缺陷、宿主调度挡不住的，出包时由 C 改写器按构建号精确改字（`runtime/rewriter/rewriter.c` `fix_rows`，环境变量 `S2A_FIX_TSV`）。

- 行格式同帧率表 c 行，只收 `word` 种类：`c <模块> <偏移> word <原字> <新字>    # 理由`（偏移、字都是十六进制；字是小端 32 位指令字）。
- 原字不符（不是这一版）或点不在代码段：记改写缺口、不改。
- 与 `runtime/fps/` 分开：帧率表存在本身表示「本款已有我方帧率表」（社区帧率补丁不收），修补表不带这层含义。以后与按款旋钮表合并时按同一格式并入。
- 每条写清依据：崩溃现场、竞争过程、为什么改成这样不丢功能。
